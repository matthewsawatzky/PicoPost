Usage

Add comments, chat, reviews, or a guestbook to your site with a script tag and a few lines of JavaScript.

1. Include the client

Serve picopost.js from your PicoPost server (it is also in the repo at web/picopost.js), or copy it into your own static assets. No npm, no build step.

<script src="https://posts.example.com/picopost.js"></script>

2. Initialize

Point the client at your server and pick a channel. Channels are just validated strings like chat/general, comments/article-123, or reviews/homepage — you decide the naming scheme.

PicoPost.init({
  server: "https://posts.example.com",
  channel: "comments/article-123"
});

3. Send posts

// Plain text
PicoPost.send("Really nice article!");

// With metadata (any JSON you like)
PicoPost.send("Loved it", { stars: 5, type: "review" });

// Anonymous post with an untrusted display name
PicoPost.sendAnon("Signed the guestbook", null, "Guest");

4. Read posts

PicoPost.list().then(function (posts) {
  posts.forEach(function (post) {
    console.log(post.display_name || "anonymous", ":", post.text);
  });
});

// Pagination: pass the last post of the previous page as the cursor
PicoPost.list({ limit: 20, before: last.created_at, before_id: last.id });

5. Live updates

Subscribe to receive new posts the moment they are accepted. The client reconnects automatically.

PicoPost.subscribe(function (post) {
  appendPost(post); // your rendering code
});

6. Identities

On first use the client creates a browser identity and stores the secret key in localStorage. It restores the identity on later visits and authenticates automatically — no login screen, no accounts.

PicoPost.identity.get().then(function (ident) {
  console.log("I am", ident.id);
});

// Let the visitor choose a display name
PicoPost.identity.setName("Mat").then(function () {
  // future posts are attributed to "Mat" by the server
});

// Forget the identity (a new one is created on next use)
PicoPost.identity.reset();
The server decides who a post belongs to. A visitor cannot change name = "Admin" in DevTools and impersonate someone — client-supplied names are ignored for authenticated identities.

7. Multiple widgets on one page

Each PicoPost.create() call returns an independent instance with its own identity, stream, and channel.

var chat = PicoPost.create({ server: "https://posts.example.com", channel: "chat/general" });
var reviews = PicoPost.create({ server: "https://posts.example.com", channel: "reviews/homepage" });

chat.send("hello");
reviews.send("Great", { stars: 5 });

8. The HTTP API

Everything the client does is plain HTTP, so you can call it from anywhere.

EndpointPurpose
GET /healthliveness check
POST /v1/identitycreate a browser identity → {id, key}
GET /v1/identityfetch your identity (Bearer auth)
PATCH /v1/identityset display name: {"name": "Mat"}
POST /v1/postscreate a post
GET /v1/postslist posts (channel, limit, before, before_id)
GET /v1/posts/{id}fetch one post
GET /v1/streamSSE live stream (?channel=…)
# Create a post
curl -X POST https://posts.example.com/v1/posts \
  -H "Content-Type: application/json" \
  -d '{"channel":"chat/general","text":"hello","meta":{"stars":5}}'

# List a channel
curl "https://posts.example.com/v1/posts?channel=chat/general&limit=20"

# Live stream
curl -N "https://posts.example.com/v1/stream?channel=chat/general"

9. Errors

Errors are small JSON objects with a stable code:

{
  "error": "post_rejected"
}
CodeMeaning
invalid_requestmalformed JSON, bad field, or a limit was exceeded
payload_too_largerequest body exceeded max_body_bytes (HTTP 413)
post_rejecteda filter matched (text, username, or URL count)
rate_limitedtoo many posts from this IP (HTTP 429)
unauthorizedmissing or invalid identity key
not_foundno such post
invalid_channelchannel name has invalid characters

10. CORS

Your site and the PicoPost server are usually on different domains. Add your site's origin to [cors] origins in the server config and the browser will be allowed to call the API. Preflight requests are handled automatically.

[cors]
origins = [
  "https://example.com",
  "https://your-site.pages.dev"
]
